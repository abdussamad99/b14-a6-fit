## Project Name

FitLog - Workout Library & Planner

## Short Description

FitLog is a dark-themed fitness web application built with Next.js. It allows users to browse a library of workouts, view detailed exercise instructions, save their favorite workouts, and build a daily workout plan to track their fitness goals.

## Technologies Used

· Framework: Next.js 16 (App Router)
· Language: TypeScript
· Styling: Tailwind CSS & DaisyUI
· Icons: Lucide React
· State Management: React Context API
· Notifications: React Hot Toast

## 5 Key Features of the Project

1. Workout Library & Details: Users can browse all available workouts and click "View Details" to see specific information like equipment, sets, reps, duration, calories, and step-by-step instructions.
2. Today's Plan Management: Users can add workouts to their "Today's Plan" and mark them as "Done" once completed, which visually updates the UI to show progress.
3. Saved Workouts Tab: Users can save workouts for later. The saved tab allows them to view details or remove the workout from their saved list.
4. Dynamic Sorting & Statistics: Users can sort workouts by Duration, Calories, or Rating. The page also dynamically calculates and displays total exercises, total minutes, and total calories for the current plan.
5. Dynamic Routing & Responsive UI: Utilizes Next.js dynamic routing (/workout/[id]) to load specific workout data. The entire app is fully responsive with a custom dark theme and neon green accents for a modern gym aesthetic.
