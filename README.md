
#  FitLog - Workout Library & Planner

FitLog is a dark-themed fitness application where users can browse various workouts, save their favorite ones, and create a plan for today.

##  Features
- **Workout Library:** Browse a list of all workouts with detailed information (Equipment, Sets, Reps, Duration, Calories, Rating).
- **Today's Plan:** Add specific workouts to your daily plan and mark them as done when finished.
- **Saved Workouts:** Save your favorite workouts and remove them whenever you want.
- **Sorting:** Sort workouts by Duration, Calories, or Rating.
- **Responsive Design:** Works perfectly on both mobile and desktop devices.
- **Dark Theme:** A sleek dark theme with a neon green accent color.

##  Technologies Used
- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **State Management:** React Context API
- **Notifications:** React Hot Toast
- **Language:** TypeScript
